# ATLAS Marketing Site

This folder is a standalone static marketing website for GitHub Pages.

## Publish with GitHub Pages

1. Copy the contents of this folder to the root of the repository that will host `atlas.uni-protect.com`.
2. Keep `index.html` and the `assets` folder together.
3. In GitHub, open **Settings > Pages** and publish from the repository branch containing these files.
4. Add `atlas.uni-protect.com` as the custom domain and configure the DNS records required by GitHub Pages.
5. Enable **Enforce HTTPS** after GitHub confirms the domain.

The website uses only HTML, CSS, JavaScript, and local images. PHP is intentionally not required because GitHub Pages does not execute PHP.

The product screenshots are captured from the live local ATLAS application. Replace them with newer captures in `assets` whenever the application interface changes materially.
